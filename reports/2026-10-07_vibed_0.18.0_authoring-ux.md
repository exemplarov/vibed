# 2026-10-07 — vibed: block authoring UX (0.18.0)

## What was built

The "recall the block syntax" friction is gone via three standard
Obsidian-native affordances (non-AI; agent-side leveraging deferred to a
later version). Spec: `spec/008-authoring-ux.md`.

- **Insert command** — *Insert session dashboard block*: a modal form
  (connector, layout, basedir, dirs, tags, session ids, pageSize, title +
  collapsible session-config fields with an *extra config lines* raw
  escape hatch) composing the block through the shared pure
  `composeVibedBlock()` and inserting at the cursor. A live `<pre>` preview
  recomputes on every keystroke — the preview doubles as the syntax lesson.
- **Autocomplete in fences** — `VibedBlockSuggest extends EditorSuggest`,
  scoped to ```vibed fences by an upward fence scan. Suggests: all keys
  with one-line docs (`VIBED_BLOCK_KEYS`), live connector names
  (`registry.enabled()`), `layout:` values, and `- ` items under `dirs:`
  from the named connector's configured directories. Cursor-position
  classification lives in the pure `analyzeVibedLine()`.
- **Copy as vibed block** — clipboard icon on every non-widget dashboard
  toolbar: serializes block options + active filter back into a block
  (`#tag` criteria merge into `tags:`; `is:`/`dir:`/`model:`/text ride
  along as a `# active filter: …` comment, which the parser skips). The
  dedicated view copies too (its internal title is chrome, not config).
- **Embedded agent reference** — the canonical block cheatsheet now ships
  inside the plugin (`AGENT_REFERENCE_MD` in main.js). *Save AI agent
  reference (AGENTS.md)* → folder picker (vault root default) →
  writes/updates a managed section between `<!-- vibed:begin/end -->`
  markers via the pure `applyAgentReference()`. Idempotent re-runs;
  user content outside the markers is never touched; version-stamped from
  the manifest at write time. Vaults stop hand-maintaining copies.
- **Repo AGENTS.md** — created (was missing): dev model, code map,
  release checklist, and the DSL quick reference with the
  three-places-one-truth rule (README tables, `AGENT_REFERENCE_MD`, quick
  reference).
