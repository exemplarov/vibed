## Review fixes worth remembering

- **B1**: driver-level flag checks must use `blockFlag()` (string "true"
  from the simple block format); `session.archived`/`unarchived` added to
  `LIST_REFRESH_EVENTS` so archiving refreshes dashboards promptly.
- **B2**: a late global-elicitation poll must not clobber an own-session
  question that arrived in flight (own wins — it blocks the session);
  global pendings don't touch the session's badge/live state; reply target
  pins the directory captured at poll time.
- **B3**: the "Archived" badge needed the *live-idle* branch too (the final
  `else` only runs with the stream down); rename modal needed a
  reentrancy guard; empty rename title = server regenerates (verified
  upstream: falsy title → `title.generate`).
- **B5**: the dominant real-world file block is a **data: URI from the
  `read` tool** — labels must derive from mime (not the base64), no Open
  button, tooltip truncated, preview capped at ~1.5 MB, and auto-expand
  only on the live tail (a transcript of auto-expanded images decodes
  every bitmap on load).
